# Coffee Sales Analysis Project

A study project demonstrating two scenarios for working with data hosted on GitHub repository using **Jupyter Notebook** on **Google Colab** directly.

## Scenario 1: Public GitHub repository

- Loads data directly from `raw.githubusercontent.com`
- Clones the entire GitHub repo
- Uses GitHub API to get data

## Scenario 2: Private GitHub repository

- Loads data manually through Colab interface
- Mounts Google Drive
- Uses GitHub temporary token to load data directly
